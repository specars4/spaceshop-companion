W H A T   H A P P E N S   N E X T
  1. Paste your invite code and click Continue.
  2. Pick the folder where the project files should live (the default is fine), then click Connect.
  3. Click Yes when Windows asks for permission.
  4. Sit back while Companion downloads the project. The first time can take a while on a big project — go grab a coffee. You'll see the file count ticking up so you know it's working.
  5. When the project page appears, click Open in Unreal — and you're working.
